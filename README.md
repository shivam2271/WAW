Where Are We (WAW)

Prototype web app to share live locations among participants who join a room link.

Getting started

1. Install dependencies: npm install
2. Create a free Supabase project and run `supabase/schema.sql` in the SQL Editor.
3. Copy `.env.example` to `.env` and add the project URL and anon key from Supabase settings.
4. npm run dev

Notes
- This is an initial scaffold. Secure the public room policies before production.
